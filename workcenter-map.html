Admin: connection setup (not needed for normal users)

Normal users need no setup — the shared endpoint and token are built into this app and auto-sync is on by default.

  1. Create a Google Sheet (or open an existing one).
  2. Open Extensions → Apps Script, delete the starter code, and paste the script google-sheet-sync.gs.
  3. Set TOKEN in the script to a long random value, or set SYNC_TOKEN under Project Settings → Script properties. Use the same token in this page.
  4. Click Deploy → New deployment → Web app. Execute as Me, who has access Anyone. Deploy and authorize.
  5. Copy the Web App URL ending in /exec, paste it above, enter the token, tick auto-sync and click Save settings.
  6. Click Test connection, then Push all to Sheet. On other phones, use the same URL and token and press Pull from Sheet.

The shared sheet is link-accessible — keep the sheet link private. Photos are not uploaded to the Sheet.

Field workflow

Repeat this for every machine, line, bay, store and utility area in the factory.

1
Walk thereStand at the work center or its operator station.
2
Get a fixWait 20–30 s until accuracy turns green.
3
Fine-tuneTap the map to move the pin onto the exact spot.
4
Name itAdd code, SBU, zone and category; attach a photo.
5
Go liveOpen Live map to see everything with your position.
  • Use the SBU selector in the topbar to scope the capture map, live map, work center list and nearest-center distance.
  • Indoor GPS drifts. Stand still, prefer green accuracy (<10 m), and correct the pin by tapping the map.
  • Use satellite view — the factory roof, silos and sheds make verification easy.
  • Export JSON regularly; it is your backup and can be imported on another device.
  • Photo attachments are compressed and stored locally, so keep them small in number.
